# Patient-Side Routes & Functionality

| Route                   | Description                                                                                                                                                                                                                                                                              |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/login`, `/register`   | Standard authentication. Registration automatically links the account to a synthetic patient record populated with initial clinical chart history.                                                                                                                                       |
| `/patient` (Dashboard)  | Displays upcoming appointments, active waitlist entries with status indicators (waiting / offered — claim now! / expired), insurance & prior-auth summaries for upcoming visits, and quick-action triggers ('Book an appointment', 'Upload a bill').                                     |
| `/patient/book`         | **4-step workflow**: (1) Pick visit reason/type; (2) Pick preferred date range and time preference; (3) System evaluates slot constraints server-side and returns matches; (4) Confirm slot to create booking. If no slot matches, prompts joining the waitlist with identical criteria. |
| `/patient/waitlist`     | Displays active waitlist entries with live status. Matches trigger a status flip to 'Offered — claim within [countdown]' with Confirm/Decline options. Includes past waitlist history.                                                                                                   |
| `/patient/appointments` | Complete list of upcoming and past visits. Per-appointment details show date/time, provider, insurance eligibility, and prior-auth status (not needed / pending / submitted / denied / appealed / approved).                                                                             |
| `/patient/bills`        | Bill upload interface (PDF/image). Features automatic line-item extraction into a structured table, rule-flagged errors (not covered / duplicate / coding mismatch), plain-language explanations upon selection, and auto-drafted self-service dispute letters for download.             |

# Staff-Side Routes & Functionality

| Route                | Description                                                                                                                                                                                                                                                             |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/staff` (Dashboard) | Daily operational overview showing today's appointment load, pending prior-authorizations, pending appeals, and waitlists with open slots. Includes provider and patient search lookup bars.                                                                            |
| `/staff/schedule`    | Provider schedule view by day/week. Selecting an appointment opens the Pre-Visit Summary Panel containing an auto-generated narrative summary alongside raw chart data (encounters, labs, medication changes).                                                          |
| `/staff/slots`       | Resource utilization overview (rooms, providers, equipment) for any selected date. Features manual override controls (cancel/reschedule triggering waitlist auto-fill) and real-time waitlist offer monitoring.                                                         |
| `/staff/prior-auth`  | Queue of bookings requiring prior authorization grouped by workflow status: **Needs Draft** → **Drafted** (pending review) → **Submitted** → **Approved / Denied**. Displays auto-generated chart justification text; editable by staff, submittable by elevated staff. |
| `/staff/appeals`     | Queue of denied prior-authorizations requiring appeal. Displays matched clinical guideline excerpts, chart justification, and drafted appeal letters. Editable by staff, submittable by elevated staff.                                                                 |
| `/staff/disputes`    | Read-only operational list of patient-submitted bill disputes and flagged line-item issues for institutional visibility.                                                                                                                                                |
