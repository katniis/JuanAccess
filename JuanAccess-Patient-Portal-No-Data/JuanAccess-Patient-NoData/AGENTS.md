# JuanAccess

React + Vite + Tailwind CSS project.

## Development
Install dependencies with `pnpm install` or `npm install`, then run `npm run dev`.
The application entrypoint is `src/main.tsx`; the main application shell is `src/App.tsx`.

## Project structure
- `src/` contains the React pages, shared components, types, and data.
- `index.html` provides the browser document shell and JuanAccess page title.
- `vite.config.ts` configures Vite, React, Tailwind CSS v4, and the source alias.
